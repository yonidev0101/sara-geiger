# מזמור לשרה

מערכת לחלוקת ספר תהילים בין אנשים, לעילוי נשמת **שרה בת צבי ז״ל** (שרה גייגר).

כל אחד יכול לפתוח חלוקה, לשתף קישור, ולראות בזמן אמת אילו פרקים נלקחו, אילו נקראו ומה עוד פנוי.

## מה יש במערכת

האתר בנוי כמו אפליקציה: סרגל עליון, ארבע לשוניות בתחתית (בית, הקריאה שלי, תהילים, חלוקה חדשה), ואפשר להתקין אותו למסך הבית בטלפון (PWA).

- **פתיחת חלוקה בשלושה שלבים**: איך לחלק (לפי פרקים, ימי החודש, ימי השבוע או חמשת הספרים), שם, ופרטים לא חובה.
- **בחירת חלקים** בלחיצה, או "בחרו בשבילי". אם שניים בוחרים את אותו חלק באותו רגע, רק אחד מקבל אותו.
- **התקדמות לפי פרק**: מי שלקח ספר או יום רואה את רשימת הפרקים שבו, ומסמן כל פרק. בסוף כל פרק בקורא יש "קראתי" או "עוד לא". כשכל הפרקים מסומנים, החלק נחשב כנקרא.
- **קורא נוח**: פסוק בכל שורה, גודל גופן, וטעמי המקרא לפי בחירה.
- **עדכון בזמן אמת** לכל מי שהדף פתוח אצלו (Server-Sent Events דרך Postgres `LISTEN/NOTIFY`).
- **הקריאה שלי**: כל מה שלקחת, מכל החלוקות, עם התקדמות.
- **שמות נוספים** לעילוי נשמה, לרפואה או להצלחה.
- **סבבים**: כשהספר מושלם מופיע מסך סיום, ומתחיל סבב חדש.
- **ניהול**: קישור ניהול פרטי לכל חלוקה (נשמר במכשיר שפתח אותה). שיתוף, מי קורא ובאיזה שלב, הורדה לאקסל, הסתרת שמות, הגדרות ושחרור אוטומטי.

## הרצה מקומית

צריך Node 20 ומעלה ו-Postgres.

```bash
cp .env.example .env.local   # ולעדכן את DATABASE_URL
npm install
npm run dev
```

הטבלאות נוצרות אוטומטית בחיבור הראשון.

בדיקות: `npm test`. בדיקת טיפוסים: `npm run typecheck`.

## העלאה ל-Railway

1. יוצרים פרויקט חדש ב-Railway ומחברים אליו את הריפו הזה.
2. מוסיפים לפרויקט שירות **Postgres** (New → Database → PostgreSQL).
3. בשירות של האתר, תחת Variables, מוסיפים `DATABASE_URL` עם הערך `${{Postgres.DATABASE_URL}}`.
4. תחת Settings → Networking יוצרים דומיין (או מחברים דומיין משלכם).

ההגדרות של ה-build וההפעלה נמצאות ב-`railway.json`, כולל בדיקת תקינות ב-`/api/health`.

## התאמה אישית

פרטי הזיכרון נמצאים ב-`src/lib/site.ts`: שם המותג, תאריך הפטירה העברי, כמה מילים על שרה ותמונה (שמים את הקובץ ב-`public/`).
