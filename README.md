# מזמור לשרה

מערכת לחלוקת ספר תהילים בין אנשים, לעילוי נשמת **שרה בת צבי ז״ל** (שרה גייגר).

כל אחד יכול לפתוח חלוקה, לשתף קישור, ולראות בזמן אמת אילו פרקים נלקחו, אילו נקראו ומה עוד פנוי.

## מה יש במערכת

- **ארבעה סוגי חלוקה**: לפי פרקים (150, עם אפשרות לפצל את פרק קי״ט ל-22 חלקים לפי האותיות), לפי ימי החודש (30), לפי ימי השבוע (7) ולפי חמשת הספרים.
- **בחירת פרקים** בלחיצה, או "תנו לי פרקים" שבוחר אוטומטית את הפנויים הבאים.
- **עדכון בזמן אמת**: כשמישהו לוקח פרק, הוא נצבע מיד אצל כל מי שהדף פתוח אצלו (Server-Sent Events דרך Postgres `LISTEN/NOTIFY`).
- **הגנה מכפילות**: אם שניים לוקחים את אותו פרק באותו רגע, רק אחד מקבל אותו.
- **"הפרקים שלי"** לפי המכשיר, בלי הרשמה: קישור לטקסט בספריא, סימון "קראתי" ושחרור.
- **שמות נוספים**: לעילוי נשמת, לרפואת או להצלחת, נוסף לשמה של שרה.
- **סבבים**: כשהספר מושלם, מתחיל סבב חדש אוטומטית, ונספרים הספרים השלמים.
- **ניהול**: מי שפותח חלוקה מקבל קישור ניהול פרטי. משם אפשר לראות מי לקח מה, לשחרר, לסמן כנקרא, להסתיר שמות, לשנות הגדרות, לפתוח סבב חדש ולסגור.

## הרצה מקומית

צריך Node 20 ומעלה ו-Postgres.

```bash
cp .env.example .env.local   # ולעדכן את DATABASE_URL
npm install
npm run dev
```

הטבלאות נוצרות אוטומטית בחיבור הראשון.

בדיקות: `npm test`. בדיקת טיפוסים: `npm run typecheck`.

## העלאה ל-Railway

1. יוצרים פרויקט חדש ב-Railway ומחברים אליו את הריפו הזה.
2. מוסיפים לפרויקט שירות **Postgres** (New → Database → PostgreSQL).
3. בשירות של האתר, תחת Variables, מוסיפים `DATABASE_URL` עם הערך `${{Postgres.DATABASE_URL}}`.
4. תחת Settings → Networking יוצרים דומיין (או מחברים דומיין משלכם).

ההגדרות של ה-build וההפעלה נמצאות ב-`railway.json`, כולל בדיקת תקינות ב-`/api/health`.

## התאמה אישית

פרטי הזיכרון נמצאים ב-`src/lib/site.ts`: שם המותג, תאריך הפטירה העברי, כמה מילים על שרה ותמונה (שמים את הקובץ ב-`public/`).
